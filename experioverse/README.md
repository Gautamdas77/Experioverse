# Experio Verse — Next.js Application

> Next.js 16 (React 19) app for Experio Verse Corporate Employee Experience Platform.

For full project documentation, requirements, and architecture, please see the [Root README.md](../README.md).

## Quick Start

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
